# devforge

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-blue?style=for-the-badge)](https://mayank-dev-15.github.io/devforge)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Language](https://img.shields.io/badge/Language-JavaScript/Python-green)

Swiss-army knife developer hub with JSON formatter, regex tester, hash generator, API playground, and more.

`developer-tools` `json` `regex` `hash` `productivity`

---

## ✨ Features

- JSON formatter and validator
- Regex tester with match highlighting
- Hash generator (MD5, SHA-1, SHA-256, SHA-512)
- API playground (send HTTP requests)
- Base64 encoder/decoder
- JWT decoder
- URL encoder/decoder
- Color picker and converter (HEX, RGB, HSL)
- Timestamp converter
- Markdown live previewer

## 📦 Installation

```bash
git clone https://github.com/mayank-dev-15/devforge.git
cd devforge
```

```bash
cd devforge
open index.html
# Or serve with Python
python -m http.server 8080
```

---

## 💡 Usage

- Select a tool from the sidebar
- Enter your input in the text area
- Click the action button to process
- Copy results with one click
- All processing happens client-side (no data sent to servers)
