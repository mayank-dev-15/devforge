## About

**devforge** is a developer tools hub.

### Key Features

- JSON formatter and validator
- Regex tester with match highlighting
- Hash generator (MD5, SHA-1, SHA-256)
- API playground (send HTTP requests)
- Base64 encoder/decoder
- JWT decoder
- URL encoder/decoder
- Color picker and converter
- Timestamp converter
- Markdown previewer

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Crypto API
- Python backend

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `Select tool` | Switch between tools |
| `Input area` | Enter data |
| `Format/Run` | Process output |
| `Copy` | Copy result |
| `Clear` | Reset input |
